🎬 ভিজ্যুয়াল ভিডিও স্টুডিও

কোড ছাড়াই সব সেটিংস — ফলব্যাক চেইন, মাল্টি API কী ব্যবস্থা, রান স্পেসা

▶️ এক-ক্লিক রান run.spec.json

নিচের সেটিংস ঠিক করে রান-ফাইল ডাউনলোড চাপুন। তারপর গাইডের মতো ফাইলটি রিপোজিটরিতে আপলোড করলেই পরের পুশে অটো-রান হবে।

রান-ফাইলে কোনো API কী বা টোকেন যায় না — শুধু কী ভিডিও বানাবেন সেটাই।

🔑 মাল্টি API কী সেটআপ GitHub Secrets

⚠️ কী কখনো এই পেজে, কোডে বা রিপোতে পাবলিকভাবে রাখবেন না। সব কী শুধু Settings → Secrets and variables → Actions-এ যাবে। এই পেজ কোনো কী সেভ বা পাঠায় না — নিচের হিসাব-নিকাশও শুধু আপনার ফোনে হয়।

একই সার্ভিসের একাধিক কী এক সিক্রেটে কমা দিয়ে বসান; একটি কী-তে লিমিট/এরর হলে পাইপলাইন নিজেই পরেরটিতে চলে যায়। পুরনো একক সিক্রেটও (যেমন GEMINI_API_KEY) কাজ করবে।

🧮 কী-ফরম্যাট প্রস্তুতকারী (ফোনে, নিরাপদ)

কী-গুলো আলাদা লাইনে পেস্ট করুন — উনাকে কমা-ফরম্যাটে ছাঁটাই করে দেখাবে। ফলাফল কোথাও সংরক্ষণ হয় না; কপি করে Secrets-এ বসান।

💡 আরও নিরাপদ: প্রতিটি কী আলাদা সিক্রেটে বসাতে চাইলে GEMINI_API_KEY, GEMINI_API_KEY_2, GEMINI_API_KEY_3… নাম দিতে পারেন — ওয়ার্কফ্লো সেগুলো একসাথে জুড়ে GEMINI_API_KEYS বানিয়ে নেয়।

🛡️ ফলব্যাক চেইন workflow_config.json

প্রতিটি ধাপে উপর থেকে চেষ্টা হবে; একটি ফেল/লিমিট করলে নিচের টুলে অটো-সুইচ। অর্ডার বদলান (▲▼ বা ড্র্যাগ), অফ/অন করুন, নতুন টুল যোগ করুন।

🧩 মডিউল অন/অফ

ফলব্যাক ভয়েসে আপনার ক্লোন কণ্ঠ থাকবে না — নিচ থেকে নমুনা শুনে বেছে নিতে পারেন।

🗣️ বাংলা ভয়েসের নমুনা-তালিকা
  • bn-BD-NabanitaNeural (নারী, বাংলাদেশ)
  • bn-BD-PradeepNeural (পুরুষ, বাংলাদেশ)
  • bn-IN-BashkarNeural (পুরুষ, ভারত)
  • bn-IN-TanishaaNeural (নারী, ভারত)

📖 স্ক্রিপ্ট-নিয়ম ও উচ্চারণ project.txt / pronounce.json

এই দুটি ফাইল এখন ছবির সেটিংসে সরাসরি রিপোর Add file দিয়ে বদলাতে হয় (তাতে আলাদা ডাউনলোড লাগে না):

  • project.txt — Gemini কী ধরনের লেখক হবে তার নিয়ম।
  • pronounce.json — ইংরেজি শব্দের বাংলা উচ্চারণ-তালিকা (JSON: "ভিডিও": "ভিডিও")।
  • projects.json — প্রিসেট (dropdown-এ দেখাবে)।

📟 ড্যাশবোর্ড যাচাই

নিচের রিপো-স্ট্যাটাস বাটনে চাপলে রিপোর সর্বশেষ Actions রানের ফল দেখা যাবে (পাবলিক রিপো, কোনো টোকেন লাগে না)। Secrets-এ কী আছে কিনা তা কখনো দেখা যায় না — GitHub নীতিমালা।
