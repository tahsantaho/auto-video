# 🎬 বাংলা ভিডিও অটোমেশন স্টুডিও (GitHub Actions)

ফোন থেকেই চালানো যায় — কোডিং লাগে না। **ভিজ্যুয়াল ড্যাশবোর্ড + মাল্টি API কী + ধাপে ধাপে অটো-ফলব্যাক** সিস্টেম যুক্ত হয়েছে।

---

## নতুন কী-কী যোগ হলো (এডিট: ২০২৫)

| ফাইল | কাজ |
|---|---|
| `docs/index.html` | 🖥️ ভিজ্যুয়াল কাস্টমাইজার ড্যাশবোর্ড (GitHub Pages-এ হোস্ট হবে) — মোড/সাইজ/রেজোলিউশন/থিম, ফলব্যাক চেইন ড্র্যাগ-ড্রপ বা ▲▼ দিয়ে সাজানো, মডিউল অন/অফ, মাল্টি-কি গাইড ও ফরম্যাটার (কী সেখানে *সেভ হয় না*), সর্বশেষ Actions রান-স্ট্যাটাস দেখা |
| `config/workflow_config.json` | ড্যাশবোর্ড থেকে ডাউনলোড করে রিপোতে আপলোড করার কেন্দ্রীয় কনফিগ — কোড ছোঁয়ার দরকার নেই |
| `pipeline.mjs` | ✅ মাল্টি API কী রোটেশন (Gemini/Cartesia/Pixabay/Pexels), ✅ একাধিক ক্লোন Voice ID ফলব্যাক, ✅ কাস্টম সাইজ (উদা. `720x1280`), ✅ রেজোলিউশন `480p/720p/1080p`, ✅ মডিউল-টগল (SFX/সাবটাইটেল/থাম্বনেইল), ✅ কোন কী চলল/বা কোন কী ফেল করল তা লগে |
| `tools/drive_upload.mjs` | Google Drive-এ ভিডিও সেভ (চেকপয়েন্ট) — ঐচ্ছিক, সিক্রেট দিলেই চালু |
| `apps_script/Code.gs` | Apps Script দিয়ে ঢাকা-সময়ে অটো ট্রিগার (GitHub cron-এর বিলম্ব/৬০-দিন-বন্ধের ঝুঁকি এড়াতে), পাসফ্রেজ-যাচাইসহ |
| `.github/workflows/video.yml` | মাল্টি-কি সিক্রেট, `repository_dispatch` ট্রিগার, পাসফ্রেজ গেট, বাংলা ফন্ট ইনস্টল, Drive-আপলোড ধাপ |
| `.github/workflows/pages.yml` | ড্যাশবোর্ড অটো-ডিপ্লয় |

### পুরনো যা ছিল (অপরিবর্তিত কাজ করছে)
- Remotion-ভিত্তিক রেন্ডার (বাংলা যুক্তাক্ষর Chromium দিয়ে রেন্ডার হয় — এ কারণেই Node+Remotion বাছা; ffmpeg+drawtext এ যুক্তাক্ষর ভাঙে), ক্যারেক্টার-অ্যানিমেটেড সাবটাইটেল, থাম্বনেইল, অটো-গান/SFX, `script_only → voice_test → draft → full` মোড, provider ফলব্যাক চেইন, রিট্রাই, `data/log.txt`।

## 🍀 ড্যাশবোর্ড কীভাবে চালু করবেন (একবার, ১ মিনিট)

1. सब ফাইল merge হওয়ার পর: রিপো → **Settings → Pages → Build and deployment → Source: GitHub Actions** বাছুন।
2. `Dashboard Pages` ওয়ার্কফ্লো অটো চলবে → ঠিকানা: `https://tahsantaho.github.io/auto-video/`
3. সেই ঠিকানা ফোনের বুকমার্কে রাখুন — এখান থেকেই এখন সব সেটিংস বদলাবেন।

> ড্যাশবোর্ডে বদলানোর পর: **⚙️ কনফিগ ডাউনলোড** → রিপোর `config/` ফোল্ডারে **Add file → Upload** → `workflow_config.json` নামে কমিট। এভাবেই আপডেট চলে (নিরাপত্তার কারণে পেজ সরাসরি রিপোতে লিখতে পারে না — লিখতে গেলে ব্রাউজারে টোকেন রাখতে হয়, যা আমরা স্পষ্টভাবে বাদ দিয়েছি।)

## 🔑 Secrets সেটআপ (Settings → Secrets and variables → Actions)

একই সার্ভিসের **একাধিক কী এক সিক্রেটে কমা দিয়ে** দিন; **অথবা** নম্বরসহ আলাদা সিক্রেটে:

| সিক্রেট নাম | মান | বাধ্যতামূলক? |
|---|---|---|
| `GEMINI_API_KEYS` | কমা/নতুন লাইন-স্পষ্ট একাধিক কী অথবা `GEMINI_API_KEY`, `GEMINI_API_KEY_2`…`_5` আলাদা সিক্রেটে | Gemini স্ক্রিপ্টের জন্য দরকার |
| `CARTESIA_API_KEYS` | কমা-দৃষ্টিতে একাধিক কী (একক `CARTESIA_API_KEY`-ও চলবে) | ক্লোন কণ্ঠ চাইলে |
| `CARTESIA_VOICE_ID` / `CARTESIA_VOICE_IDS` | ক্লোন ভয়েস আইডি (একাধিক হলে কমা) | Cartesia হলে |
| `PIXABAY_API_KEYS` | কমা-দৃষ্টির একাধিক ফুল-কী (অথবা `PIXABAY_API_KEY`, `_2`…`_5`) | ভিজ্যুয়ালের জন্য |
| `PEXELS_API_KEYS` | বিকল্প ভিজ্যুয়াল সোর্স | ঐচ্ছিক |
| `PIPE_PASSPHRASE` | লম্বা পাসফ্রেজ — Apps Script-এর সাথে মিলবে | Apps Script ট্রিগার ব্যবহার করলে |
| `GOOGLE_REFRESH_TOKEN`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_DRIVE_FOLDER_ID` | Drive চেকপয়েন্ট আপলোড | ঐচ্ছিক — না দিলে এই ধাপ লাফাবে |

⚠️ কোনো কী চ্যাট/ইমেইল/কোড-ব্লকে আগে-পরে প্রকাশ হয়ে থাকলে সেই কী প্রোভাইডারের ড্যাশবোর্ড থেকে **রিসেট** করে নতুন কী Secrets-এ বসান।

**কীভাবে ফলব্যাক চলে:** কী-গুলো সাজানো তালিকায় চেষ্টা হয় → কোনোটিতে লিমিট/400/403/429/ইনভ্যালিড হলে লগে লেখা রাখে → পরের কী → সব কী শেষ হলে পরের মডেল/টুল (যেমন Cartesia → Edge-TTS, Pixabay ভিডিও → Pixabay ছবি → AI-ছবি → গ্রেডিয়েন্ট)।

## 📅 কীভাবে চালাবেন

**ম্যানুয়াল (সবচেয়ে সহজ):** রিপো → **Actions → Video Pipeline → Run workflow** → ঘরগুলো পূরণ → সবুজ বাটন। অথবা ড্যাশবোর্ড থেকে **রান-ফাইল ডাউনলোড** → রিপোর `data/run.spec.json` রিপ্লেস/আপলোড → পরের পুশে অটো-রান।

**অটো শিডিউল:** দুটি স্তর —
- GitHub cron (রোজ UTC 13:30 = ঢাকা 19:30): বিলম্ব হতে পারে এবং ৬০ দিন রিপো নিষ্ক্রিয় থাকলে GitHub scheduled workflow বন্ধ করে দেয়।
- **Apps Script ট্রিগার (প্রস্তাবিত):** `apps_script/Code.gs` নোট-হেডারের ৫ ধাপ অনুসরণ করুন। Apps Script নিজে GitHub workflow-কে জাগায়, তাই ৬০-দিন-বন্ধ ঝুঁকি থাকে না।

**ফল কোথায়:** রান শেষে নিচে **Artifacts → video-output** (`out/video_*.mp4`, `subs.srt`, `thumb.jpg`, `metadata.json`, `log.txt`)। `GOOGLE_*` সিক্রেট দিলে ভিডিও সাথে সাথে Google Drive-এও জমা হবে।

## 📦 ইনস্টল কী লাগে — এবং কী লাগে না

**আপনাকে ইনস্টল করতে হবে না কিছুই** — Python/FFmpeg/ফন্ট/npm সব Actions রানার নিজে ইনস্টল করে (ওয়ার্কফ্লোতে লেখা আছে: `ffmpeg`, `fonts-noto-bengali`, Node 20, edge-tts চলে রান-সময়ে ইনস্টল হয়)।

আপনার একমাত্র করণীয়: **API কী সংগ্রহ → Secrets-এ বসানো**, (ঐচ্ছিক) **Apps Script authorize**, (একবার) **Pages চালু**।

> নোট: এই রিপো Python-নির্ভর নয়, তাই `requirements.txt` লাগে না — `package.json`-ই যথেষ্ট। YouTube/Facebook সরাসরি অটো-পোস্ট এখানে **নেই** (নিচের "সীমাবদ্ধতা" দেখুন)।

## ⚠️ সততার সাথে সীমাবদ্ধতা (A to Z)

1. **লাইভ টেস্ট:** পুরো সিস্টেম বাস্তব API-কীসহ চালিয়ে যাচাই এই এজেন্ট করতে পারে না (GitHub Secrets-এর মান কেউ পড়তে পারে না, রানারে Gemini/Cartesia/Pixabay লাইভ কল করার অনুমতিও এখানে নেই)। যাচাই হয়েছে: সিনট্যাক্স (`node --check`), YAML কাঠামো, কনফিগ-মার্জ ও কী-পার্সিং লজিক, ড্যাশবোর্ড JS। **যাচাই হয়নি:** লাইভ API কল, Remotion রেন্ডার, Drive আপলোড, Apps Script ডিসপ্যাচ — এগুলো প্রথম আসল রানেই পরীক্ষা হবে; লগ (`data/log.txt`) সব ধাপ ধরে রাখে।
2. **কোটা/লিমিট:** Gemini ফ্রি টিয়ার (রোজ/মিনিট ভিত্তিক লিমিট), Pixabay রোজ ~৪ হাজার রিকুয়েস্ট/কী, Cartesia ক্রেডিট — মাল্টি-কী এসব চাপ ভাগ করে দেয়, কিন্তু সব কী একসাথে শেষ হলে পাইপলাইন থামবেই (থামলে যা হয়েছিল তা লগ/আর্টিফ্যাক্টে থাকবে)।
3. **Cartesia বাংলা:** `sonic-3`-এর `bn` সাপোর্ট বাস্তব কণ্ঠ গুণমান পরীক্ষা নির্ভর। ফেল করলে অটো Edge-TTS-এ চলে যাবে — তখন ক্লোন কণ্ঠ থাকবে না (যা মনে রাখতেই হবে)।
4. **OAuth/মেয়াদ:** Google টেস্ট-মোডের refresh token ৭ দিনে মুছে যায় — Drive আপলোড চিরদিন চাইলে Google ক্লাউড OAuth কনসেন্ট-স্ক্রিন **Production** স্ট্যাটাসে রাখুন (ভেরিফিকেশন ছাড়াই আপনার নিজের ব্যবহারে চলে)।
5. **ফন্ট/রেন্ডারিং:** Noto Sans Bengali ফন্ট ওয়ার্কফ্লো ইনস্টল করে দেয়; তবুও বিরল যুক্তাক্ষর গ্লিফে সামান্য পার্থক্য হতে পারে — Remotion রেন্ডার সময় মোবাইলে ওয়াইফাই-নির্ভর নয়, কিন্তু full মোডে ২-৫ মিনিট ভিডিওতে ১০-৪০+ মিনিট রান লাগতে পারে (রানারের ৬-ঘন্টা লিমিটের ভেতরেই)।
6. **Apps Script-UrlFetch সীমা:** বড় ভিডিও কখনো Apps Script দিয়ে পাঠানো হয় না — সরাসরি Actions রানার থেকে Drive API দিয়ে যায় (`tools/drive_upload.mjs`), তাই ৫০MB UrlFetch-সীমা সমস্যা নয়।
7. **YouTube/Facebook অটো-পোস্ট:** বাদ — YouTube আপলোড API একাউন্টের OAuth-অডিট ও ঝুঁকিপূর্ণ দীর্ঘমেয়াদি টোকেন চায়; Facebook Page পোস্টিংয়ে বিজনেস-ভেরিফিকেশন লাগে। এখনকার বিকল্প: ভিডিও+metadata Artifacts/Drive-এ রেডি প্যাকেজ হিসেবে পাবেন। পরে চাইলে YouTube অপশন যোগ করা যাবে।
8. **প্রতি মাসের GitHub Actions সীমা:** ফ্রি পাবলিক রিপোতে সীমাহীন-প্রায়, কিন্তু অকারণ ঘন-ঘন full রান এড়িয়ে চলুন।

## 🗂️ কাজের গল্প (এক ঝলকে)

`trigger` → Gate (পাসফ্রেজ/নতুন run_id?) → ইনস্টল → Gemini (মাল্টি-কী×মাল্টি-মডেল) স্ক্রিপ্ট → Cartesia (মাল্টি-কী×মাল্টি-ভয়েস) বা Edge-TTS → Pixabay (মাল্টি-কী; ভিডিও→ছবি→AI) → সাবটাইটেল+SFX+গান → Remotion রেন্ডার → থাম্বনেইল → Drive (ঐচ্ছিক) → Artifacts → লগ।

প্রতিটি ধাপে রিট্রাই (২-৩ বার), প্রতিটি কী/টুল-সুইচ `data/log.txt`-এ লিখিত।
